# Red Hat Edge Manager RPM installation instructions

This document outlines the installation instructions for Red Hat Edge Manager (RHEM) for an RPM-based deployment on a RHEL 10 host.

# Pre-requisites

- A VM or baremetal RHEL 10 instance with the following specifications for a small deployment baseline for up to approximately 100 managed devices:
    - 4 vCPU
    - 4 GB RAM
    - 70 GB disk
    - Internet connectivity
